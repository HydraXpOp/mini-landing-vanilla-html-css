# Artox – Mini Landing Page

A mini desktop-focused Persian landing page built with **Vanilla HTML and CSS**.

## Overview

Artox is a simple landing page concept for a fictional digital agency. It features a clean layout, a purple color palette, and a Persian RTL design.

The project focuses on practicing core HTML and CSS skills without using frameworks such as Bootstrap or JavaScript.

## Features

- Persian RTL layout
- Desktop-focused design
- Header with navigation menu
- Hero section with call-to-action buttons
- Services section with three service cards
- Custom purple color palette using CSS variables
- Hover effects and transitions
- Custom Persian font
- Font Awesome icons

## Technologies Used

- HTML5
- CSS3
- Font Awesome

## Getting Started

1. Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

2. Open the project folder.
3. Open `index.html` in your browser.

## Note

This project is designed for desktop screens and does not currently include a responsive mobile layout.
